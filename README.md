## What it does

`main.py` (Python 3.13, standard library only) writes one line of horror — a single sentence, under 200 characters — to `/output/entry.txt`:

> The coroner called to say the body on his table had my fingerprints, my tattoo, and a heartbeat.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
